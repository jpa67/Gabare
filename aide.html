GABARE sur le FM-1, en une page

Les gestes du tracker de KAWA, et ce que Gabare y ajoute (en vert). Le détail est dans le manuel de KAWA et le README de Gabare.

Les quatre potards : K1 rouge, K2 jaune, K3 vert, K4 bleu. La ligne du bas de l'écran dit toujours ce qu'ils font. « Tenu » : garder le bouton enfoncé. Ctrl+P imprime la page.

Écrire un motif

  1. ALGORITHM choisit la piste, HOME montre le tracker.
  2. REC (curseur rouge), puis joue les touches : chaque note s'écrit à la ligne du curseur.
  3. REC tenu + SELECT : de combien de lignes le curseur saute (2 : croches, 4 : noires).
  4. Retoucher une case : SELECT la ligne, puis K1 la note, K2 le volume, K3 l'effet, K4 sa valeur.
  5. ARP efface la case ; une case OFF arrête la note d'avant.
  6. ARP tenu + SELECT : insère / ôte une ligne de la piste ; + ALGORITHM : du motif entier.

Batterie : SEQ, les 16 touches blanches sont les pas ; K1 la percussion ; un pas tenu + ARP l'efface ; OCT−/OCT+ : 16, 32 ou 64 pas.

Les sons

  1. ALGORITHM la piste, puis EDIT : la page SON.
  2. PRESETS : les sons d'usine de la piste.
  3. ARP tenu + PRESETS : le moteur suivant / précédent.
  4. K1…K4 règlent le son ; SELECT passe à SON 2, EFFET, TABLE…
  5. Un son retouché a une étoile ; PRESETS montre alors le son d'usine en doré : OCT+ le charge, OCT− garde le tien.

Le son appartient à la piste pour tout le morceau. Les volumes, panos et envois : ENV deux fois (MIX).

La piste FM : SON FM GABARE

Sur la page SON de la piste FM, K1 SON FM passe, dans l'ordre :

  1. les 12 sons de KAWA (PIANO TINE … KALIMBA) ;
  2. les 128 voix d'origine du FM-1 (M-VAVE), par groupes de quatre : PIANO, ORGAN, SYN LEAD, SYN PAD 1, puis 2… ; BASS, SYN BASS 1 à 8 sont les voix 35 à 64 ;
  3. les 32 voix de ta banque DX7, si tu en as envoyé une (dx7.html ou Fm1Studio).

La voix n° N d'origine est au cran 11 + N depuis PIANO TINE (BASS 1, n° 35 : 46 crans). PRESETS, lui, ne parcourt que les 12 sons de KAWA.

Les motifs et la chaîne

  • PRESETS (sur PISTES) : passer d'un motif à l'autre.
  • Copier un motif : MAGIE, touche 12 CLONER (dans le prochain motif vide, ajouté à la chaîne).
  • GLO : la CHAINE. ALGORITHM choisit la case, PRESETS son motif.
  • Sur le « + » au bout : une touche blanche ajoute ce motif (touche 1 : P01…). OCT+ copie la case, OCT− l'enlève.
  • K3 : répétitions ×1 à ×16 ; K1 tempo, K2 swing, K4 longueur du motif.
  • ARP : BOUCLE (le motif affiché) ou CHAINE (le morceau).
  • Jouer le morceau : mode CHAINE, curseur sur la première case, PLAY.

Les outils : SAVE tenu

  1. Tiens SAVE (la barre OUTILS se remplit).
  2. SELECT : OPTIONS, ANNULER, REFAIRE, EFFACER, COPIER, COLLER, HASARD.
  3. K3 : sur la piste du curseur (« SUR 2 FM ») ou le motif (« SUR MOTIF »).
  4. Lâche SAVE : c'est fait.

SAVE tenu + OCT− / OCT+ : annuler / refaire aussitôt (10 étapes). Copier une piste : COPIER sur elle, curseur sur l'autre piste ou un autre motif, COLLER (les notes, pas le son).

Sauver

  • SAVE, SAUVER ou SAUVER SOUS…, OCT+ ; SELECT l'emplacement.
  • Le nom : SELECT la lettre, K1 la change, K2 un nom au hasard.
  • Ensuite : SAVE puis OCT+ resauve au même endroit.
  • Nouveau morceau : SAVE, NOUVEAU MORCEAU, OCT+.

Gabare sauve tout seul dans l'emplacement AUTO quand rien ne joue.

L'arpégiateur au clavier GABARE

  • SCL deux fois : la page ARPÈGE.
  • K1 le mode (OFF, MONTE, DESCEND, MONTE+DESC, HASARD, COMME JOUÉ, REPETE, DESC+MONTE, MONTE+8VE, CONVERGE, DIVERGE, HAUT ALTERNE, BAS ALTERNE, BALADE, ACCORD), K2 la vitesse (1/32 à 1/4), K3 les octaves, K4 la durée.
  • Tiens des touches (jusqu'à 8) : elles s'arpègent sur la piste choisie, au tempo.
  • ARP (sur cette page) : garde les notes une fois lâchées.
  • REC pendant la lecture : l'arpège s'écrit dans le motif.
  • SCL encore : ARPÈGE 2, K1 swing, K2 chance, K3 tenue du clavier.

Les accords : l'effet ACC GABARE 0.6

  • Sur une case : K3 un cran à gauche de « --- » : ACC (icône ∞) ; K4 l'accord.
  • Jusqu'à 4 notes ensemble, qui partagent l'enveloppe et les effets de la piste ; l'accord tient jusqu'à la note suivante.
  • Sur CARRÉ, ONDE, FM, ANALOG, PHASE, LOFI, TRIO ; les autres moteurs jouent la note seule.
  • Chaque note de plus coûte presque une piste : quand le FM-1 sature, elles partent en premier.

Les 14 accords (ARP et ACC) : MAJ, MIN, OCT, 5TE, SUS, 7, MA7, MI7, DIM, AUG, 2OC, AD9, TRI, BAS.

Les effets de case

K3 l'effet, K4 sa valeur ; ARP tenu + K3 K4 : le second effet de la case (les deux jouent).

  • ARP arpège d'un accord
  • GLI glisse depuis la note d'avant
  • VIB vibrato
  • ROL roulé, la note rejouée 2 à 32 fois
  • BND plie la hauteur
  • CHN chance : une fois sur N
  • RET retarde la note dans la ligne
  • CUT coupe la note dans la ligne
  • HAU ±12 demi-tons pour cette note
  • FOR forme d'onde de cette note
  • ECR écrase les bits
  • VOL glissé de volume sur la ligne
  • PAN pano de cette note
  • SAU saut : la suite reprend à la ligne N
  • FIN le motif finit après cette ligne
  • ACC accord, ses notes ensemble

La MAGIE

SCL quatre fois avec Gabare (GAMME, ARPÈGE, ARPÈGE 2, MAGIE). Une touche blanche lance l'outil ; K1 sa force, K2 le dé, K3 la piste ou le motif. Tout s'annule (SAVE tenu + OCT−).

Avec Fm1Studio PC

  • Onglet FM-1, « Connecter » : le panneau « Banques FM-1 » montre les sons de Gabare, joués sur le PC (double-clic).
  • « Envoyer une banque DX7… » écrit une banque dans le FM-1, après confirmation.
  • « Importer le morceau » (Gabare 0.7) : les motifs, la chaîne, le tempo, les sons des pistes et les effets des cases, dans Fm1Studio. Rien n'est écrit dans le FM-1.
  • « Envoyer le morceau… » (Gabare 0.8) : le morceau de Fm1Studio part vers le FM-1, après confirmation (séquenceur arrêté). Le sien est d'abord gardé sur le PC. Le FM-1 affiche « MORCEAU RECU ! » : SAVE pour le garder.
  • Onglet Tracker : deux colonnes d'effets par piste, les mêmes que sur le FM-1 (une lettre choisit l'effet, les chiffres sa valeur).
  • Ferme Fm1Studio avant de flasher : un seul programme à la fois sur le port MIDI.
